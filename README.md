# Task Management System

## 🚀 Tech Stack
- Backend: Spring Boot
- Frontend: React
- Database: PostgreSQL

## ✨ Features
- User Management
- Project Management
- Task Tracking
- Filtering & Pagination
- REST APIs

## 📂 Project Structure
- /Task → Spring Boot backend
- /task-frontend → React frontend

## ▶️ How to Run

### Backend
cd Task
mvn spring-boot:run

### Frontend
cd task-frontend
npm install
npm start
